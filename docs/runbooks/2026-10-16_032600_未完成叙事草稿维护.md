# 未完成叙事草稿维护

## 入口与边界

- 生命周期、预算和准入投影在 `packages/domain/src/narrative-draft-storage.ts`、`narrative-drafts.ts`；管理面板在 `packages/ui-web/src/narrative-history/`，Web/Desktop 只接账号、存储和生成生命周期。
- 未完成草稿不进入正式历史、前情、角色状态、历战或排名。自动保留是独立本机偏好，默认关闭；生成起点冻结偏好与账号身份，迟到结果不能写进新账号。可疑整段错误/拒绝文本仅降低自动保留资格，仍提供当前结果的手动出口；不按字数判定正文真伪，也不宣称文本启发式准确识别语义。
- 传输失败、部分正文、明确内容拒绝、元数据缺失分别处理。Hosted `snapshot.status=failed` 是任务状态；合法短正文、只叙事降级和既有 Web 包完成路径保持原有合同。

## 本机存储与删除

- v2 按账号（或匿名）分 scope，条目键包含请求 ID 与正文封套摘要；不同正文不能覆盖同一 ID 的原件。这是应用层账号隔离，不是共享 OS 用户之间的安全边界。
- 删除先写独立永久 tombstone 并读回，成功后才移除已验证条目；失败保留原件和重试/导出出口。未知数据不改写。跨标签页通过 storage 事件重读当前 scope，不用旧内存整包写回。
- 单删、批量删、清空都需用户确认。清空只作用于确认时的 ID 快照，之后新生成的不同 ID 不受影响；同 ID 的列表、候选与未落盘版本一起删除。版本在确认期间变化则取消旧确认。
- localStorage 没有多键事务/CAS，不能承诺多标签页预算严格串行。每个宿主前缀计入全部 scope 的键、正文和 tombstone，按 4 Mi 字符预算接纳，预留 64 Ki 字符用于删除；并发可能暂时超额，后续新增拒绝，不淘汰已有内容。净释放空间的删除允许先写屏障再清正文；真实浏览器配额仍可能令屏障写入失败。
- tombstone 不自动回收，长期占用是已知代价；触顶后仍保留原件和导出。条数/时间淘汰与 tombstone 压缩需要另行决定，不可自行迁移清除。Desktop 页面工作副本与草稿归档分别计预算，不再重复嵌入归档。
- 未落盘状态独立于当前候选；后续生成成功不能掩盖先前失败。同 ID 冲突原文分别导出，不合并进要求唯一 ID 的批量归档；并发已持久的全部合法版本在重新打开后仍可分别查看/导出或按 ID 确认删除，不选择正文胜者。关闭保护使用不含其他账号内容的跨 scope 未保存标记。

## 旧数据与回滚

- v1 无可靠账号归属，只从“查看旧设备草稿”显式入口读取。复制到当前账号需要确认，原字节不移除；旧列表删除通过独立设备 tombstone 隐藏，不影响当前账号副本，原始导出仍保留旧内容。
- Desktop 旧页面封套可能嵌入草稿，首次重写/丢弃页面前先备份并逐字节读回。损坏、未知、备份冲突或配额失败保留原封套；用户仍可在内存编辑与导出，不能报告页面已持久保存。
- 回滚应用代码不删除 v2、旧 v1 或旧封套备份。旧应用不理解 v2 删除屏障，可能再次展示其尚未迁出的旧 v1 内容；需恢复新版管理或手动导出，不能以清库作为回滚步骤。
