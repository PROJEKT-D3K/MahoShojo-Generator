## 交付范围

Web/Desktop 的 `/local-library` 增加同一生产图片区：选择原图、填写名称、保存、重新打开列表、
预览、导出原图、软删、恢复与确认彻底删除。两端共用控制器和 UI；Desktop 接入原维护锁、
恢复挂起和离开/关闭守卫。首读在备份面板释放维护锁后重试；失效读取不覆盖新视图，预览 URL
在替换/卸载时释放。预检明确拒绝与持久操作结果未知分别反馈。

共享合同仅接受静态 PNG/JPEG/WebP，原件最多 10 MiB、单边 8192、像素积 16 × 1024 × 1024。
Web 实际浏览器解码，Native 独立真实解码；保存/导出不重编码。
SHA-256 内容身份使重复保存保留原名称、创建时间和回收站状态，正确原图可修复坏 blob。
这不是生成任务恢复，也不改变角色 JSON、签名或茶会既有媒体。

`contracts/local-image-assets` 定义纯 DTO；`local-library/image-assets` 定义仓储端口和纯字节校验；
`ui-web/local-images` 提供生产视图及生命周期；浏览器解码从专用叶子导出。应用只装配自己的
IndexedDB 或 Native IPC。共享样板间直接渲染生产组件，复用 Button、BaseModal、既有 token 与类。

## 存储、权限和备份

- Web 本地库 IDB 1→2 增加独立元数据/字节 store，同事务写入和彻底删除；旧卡和 Web 包保留。
  浏览器下载反馈仅表示已请求下载。
- Desktop 生产 SQLite 11→12 增加图片表与真实 blob 外键。blob 原子写入和资产事务持同一连接临界区；
  数据库写失败可留下可诊断孤儿，不产生缺字节记录。软删保留引用，GC 同时检查两个真实消费者。
- 未发布的 `cfg(test)` history 候选从 12 后移 13，继续保持生产隔离和原故障验证；新生产 12
  校验精确图片表形状，不能冒充旧候选。旧二进制不能降级写入新库。
- 七条窄图片命令只授予 main-ui；输入不能指定磁盘路径、SQL、远程 URL。读取返回原始 IPC 字节，
  renderer 再校验摘要/长度/格式。导出使用 Native 分配的受管文件名，原子发布后返回实际路径。
- Native 既有整库备份覆盖图片及回收站，保持 manifest 版本；恢复支持旧无图片备份。
  现有 portable V2 不加图片字段，双端改称“卡片与 Web 包归档”并说明排除独立图片。
  Web 尚无图片整库快照；单图导出/上传不携带名称时间与回收站状态。

撤回入口可保留数据；回到旧客户端需使用升级前备份及既有受控恢复流程，不提供丢表降级。
无新环境变量、线上数据库迁移、生产部署或远端凭据变更。

## 依赖影响

Native 新增 `image 0.25.10`，关闭默认 features，仅启用 png/jpeg/webp；锁文件增加本体及七个
传递包，无外部原生编解码库。image 的 MSRV 为 1.88；新增包许可分别是 MIT/Apache-2.0、
Unlicense/MIT、BSD-3-Clause/Apache-2.0 或 MIT/Apache-2.0/Zlib 的可选组合，详见锁文件对应 crate
manifest。不进入 Web bundle。Native 单飞解码和辅助 allocation 限制不等同严格进程 RSS 保证。

## 验证

共享 DTO、仓储和 UI 定向验证覆盖了边界输入、Web 仓储升级/回滚/重开及 Desktop IPC 适配。
IPC mock 不等于真实 Native command 或 ACL 验收，浏览器解码与下载仍需真实浏览器验证。

原生存储验证复用 `scripts/verify-desktop-arena-native.py`，直接编译生产源文件，覆盖实际图片解码、
损坏拒绝、共享 blob 的双消费者 GC、含图备份恢复、历史升级及审计；严格 Clippy 通过。
脚本支持重复传入 `--test-filter` 串行选择相关测试及 `--test-threads` 控制测试并发，
默认仍保留原 Arena 范围；零命中不视为成功。依赖必须是生产锁文件的版本/校验和子集，
真实源码和夹具在运行前后必须一致，否则不能生成成功证据。

升级守卫回归区分两类失败：schema 前置拒绝不预留备份目录；进入备份过程后的失败保留 invalid
目录。两类都必须保持原数据库、原件及 pending 不变，不能为满足旧测试而推迟 schema 校验。
这些结果不替代 Tauri IPC/ACL、系统 keyring、真实供应商或完整 Windows 用户旅程。
