## 实现边界

- `generateBranch` 仅在可选 branch/source 依赖齐全时可用。默认 binder、正式 IPC/ACL 和 `/battle`、`/arena` 分支入口仍关闭；Hosted 分支仍拒绝，没有改 Hosted v1 wire。
- source、generation、operation、target 与原 owner run 在模型前冻结。真实 `executeArenaDirect` 使用 `action=branch` 的 domain Prompt，复用 Direct 配置、输入预算、流解析、取消、模型及角色上限；不把分支伪装成 continue，不另写模型执行器。
- 摘要 ID 使用真实目录分页，每页 `min(50, k-seen)`，只读到 k；只保留继承摘要覆盖集合需要的 ID/index 映射，不保全前缀 ID 数组，不 hydrate 历史正文，不新增历史总量 cap。摘要覆盖集合可以是稀疏 subset；真实窗口外 ID 正确映射，未知/前缀外 ID 保持共享 domain/Web 的过滤语义。
- 分页结束即使无摘要也以原冻结 session descriptor 读取一字节封口。真实 Native 每次读取均核 instance、revision、字节长和 digest；不新 describe、不更新旧授权。进程重开、真实备份恢复和扫描中源变化拒绝旧模型准备。
- 同一个 run 在源读取、映射和凭据准备阶段检查原 selection/epoch。选走再选回不能复活旧 token；模型派发后的晚成功继续沿原设备所有权处理，不抢新选择。重复准备回调不能派发第二次模型。
- 完整成功正文、推理和 usage 先保留到原 owner，再执行角色效果、digest/cardSnapshot 与记录投影。Direct unsigned 角色效果和生成内容抽成一条共享路径；branch 直接调用 Web 已消费的 domain branch 完成组装，继承安全摘要后映射，不先走线性完成再改 action，不伪造新章摘要覆盖。
- 保存仍是原一次 completion/identity 的冻结三件包。source 冲突或投影/预算失败保文；明确 rollback 只显式重试同包，unknown 只查询原 target/op/digest，不刷新 source、不换目标、不重模型。取消、保存后目录读失败与晚成功保持原围栏。

## 兼容修复

独审发现原 Direct continue 与 Hosted 恢复 baseline 只接受 `coveredUntilChapterIndex === headCount`。正确分支保留至多 k 的摘要，而新 head 为 k+1，原条件会错误阻止后续正常续写。现仅允许安全整数 `0..headCount` 的既有摘要，保留原 mode/ID/时间验证；未来、负数和非整数仍拒绝。线性完成仍按旧逻辑推进摘要，新分支不虚报覆盖。真实内部 pipe 覆盖 branch 后原线性 continue，再从合法复制章分支。

## 分轮失败与修复留痕

- 新单测首轮发现把完整 session 直接送入 strict head schema 会被拒；改为沿已冻结 source 取目录实际需要的 id/revision，保 strict schema，不放宽DTO。独审指出的partial summary兼容问题按上文修复，修后统一516项包含新边界回归。
