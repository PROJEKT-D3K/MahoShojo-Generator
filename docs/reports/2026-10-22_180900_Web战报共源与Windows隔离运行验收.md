# Web 战报共源与 Windows 隔离运行验收

状态：本片实施与 Windows 隔离运行验收完成，已启用产品 Windows 准入；全仓 CI 未全绿，范围外阻塞见下文。对应[唯一 Desktop 计划 b2-B2](../plans/2026-09-30_160100_Desktop客户端阶段实施计划.md)；本文记录证据，不替代 DESK-013/014/015 或受限策略合同，也不宣称全部平台 D4 完成。

## 实现范围

- `ui-web/arena-report-views` 提供普通显示 / Web 显示、沉浸按钮、Web viewer chrome 与沉浸生命周期；Web 原组件实际回用，旧 CSS Module 随抽取移除，生产组件加入共享样板间。没有新增“源码模式”。
- Desktop 普通显示复用现有战报卡；Web 显示由独立零 capability 窗口承载。自由 HTML 固定为完整文档的单文件 `free-html`；精确包沿验证后的 base + overlay → snapshot → begin/append/open。完整 HTML framing 不被解释为安全认证。
- Desktop 逐次确认；取消不开始上传，来源失效停止后续派发，晚到 open 做独立清理，结果未知只查原实例、不重复打开。单次两路由共用 owner；多人结果必须 authoritative final + completed + generation record 身份。多人 Web 包尚无精确包 owner，保持不可运行。
- 新窄命令 `control_web_package_instance` 只授权 main-ui，封闭支持查询、聚焦、重载、关闭及明确全屏值。Native 自己解析 Serving 实例，不接受 label/URL/脚本。作品菜单按实例唯一 ID 路由，避免 Tauri 广播菜单事件同时控制多个窗口。
- Windows 使用 Native 自有隐藏空文档，安装 WebView2 关闭和键盘处理器后再加载作品。空文档许可一次性撤销；失败销毁。F11/Escape 在 Native 处理，页面没有获得新权限。直接引用已锁定、MIT 许可的 `webview2-com 0.39.1`，没有新依赖树。
- 平台准入读取 Native `desktop_runtime_info.os`，失败/未知/非 Windows 保持不可用；无环境开关或浏览器平台推测。确认平台不重建 owner 或来源，不清除未决窗口。

## 实机来源与隔离
